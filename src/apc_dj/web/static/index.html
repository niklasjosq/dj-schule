Hallo, DJ!

Drück eine Taste am Controller – oder tippe hier auf ein Pad.

So funktioniert's

  • Obere 4 Reihen: Loops – sie starten immer auf der nächsten Eins.
  • Mittlere 2 Reihen: Drums und DJ-Effekte.
  • Untere 2 Reihen: Keyboard – hier klingt nichts falsch!
  • Fader 1–8: Lautstärke jeder Spalte · Fader 9: Gesamtlautstärke
  • SHIFT + Fader 9: Filter (klingt wie unter Wasser)
  • Runde Knöpfe rechts: Szene 1–4, Instrument, Metronom, Modus, Alles stopp
  • ⏺ Aufnahme (oben): nimmt dein DJ-Set auf – danach kannst du es unten anhören
