# Eigene Sounds

Lege hier bis zu **4 Loops** als WAV-, AIFF- oder FLAC-Datei ab. Sie landen in **Spalte 8 („Eigene“, pink)**
in alphabetischer Reihenfolge, die erste Datei ganz oben.

* Die Loops sollten im gleichen Tempo sein wie in `config.toml` (`bpm = 120`), sonst laufen sie aus dem Takt.
* Länge: am besten genau 1, 2, 4 oder 8 Takte. Die Länge wird auf ganze Takte gerundet.
* Die Dateien werden nicht ins Git-Repo eingecheckt.
